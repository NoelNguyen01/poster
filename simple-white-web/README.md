## 🌟 Giới Thiệu
Dự án web tra cứu và đối soát dữ liệu trích dẫn nguồn chính thức phục vụ nội dung Poster Nhóm 2. Trang web được thiết kế theo phong cách tối giản cao cấp (Pure Minimalist White-to-Gray Spectrum), tích hợp dải toàn cảnh liền mạch (Continuous Panoramic Strip) và nền canvas chất lỏng động 3D.

---

## 📊 4 Cụm Nguồn Dữ Liệu Chính Thống
1. **TopDev (2024 - 2025):** Báo cáo thị trường lao động CNTT Việt Nam (750.000 kỹ sư IT, thiếu hụt ~200.000 nhân sự).
2. **Quyết định 1018/QĐ-TTg của Thủ tướng Chính phủ:** Chiến lược phát triển công nghiệp bán dẫn Việt Nam đến năm 2030, tầm nhìn 2050 (Mục tiêu 50.000 kỹ sư bán dẫn).
3. **FALMI (Dự báo Nhu cầu Nhân lực TP.HCM):** Cổng thông tin dự báo vị trí việc làm các ngành công nghiệp và dịch vụ trọng điểm.
4. **HCMUT & UIT (Đại học Quốc gia TP.HCM):** Báo cáo 3 công khai thường niên về tỷ lệ việc làm của sinh viên tốt nghiệp.

## ✨ Tính Năng Nổi Bật
- **Dải Toàn Cảnh Liền Mạch (Continuous Panoramic Strip):** Tràn viền `100vw`, không bị đóng khung trong card hộp, liên kết 4 trạm dữ liệu liên tục.
- **Hai Chế Độ Xem Linh Hoạt:**
  - `🌐 Khái Quát Toàn Dải`: Thu nhỏ đều 4 trạm trên cùng một màn hình để nhìn toàn cảnh.
  - `🔎 Phóng To Chi Tiết`: Trải rộng `82vw` tập trung xem chi tiết từng trạm.
- **Cuộn Chuột Tự Nhiên (Horizontal Mouse Wheel Gliding):** Lướt con lăn chuột dọc để di chuyển mượt mà sang trái/phải dọc theo dải.
- **Nền Sóng Động 3D (Generative 3D Kinetic Ribbons):** Vẽ bằng Canvas thời gian thực với tương tác vật lý chuột.
- **Sao Chép Liên Kết 1-Click & Âm Thanh Haptic:** Web Audio API phản hồi xúc giác nhẹ nhàng khi tương tác.

## 🚀 Hướng Dẫn Chạy Cục Bộ (Local)

### Cách 1: Sử dụng Node.js (Khuyên dùng)
```bash
node server.js
```
Mở trình duyệt truy cập: `http://localhost:3000`

### Cách 2: Mở trực tiếp
Mở file `index.html` bằng bất kỳ trình duyệt web hiện đại nào (Chrome, Edge, Safari, Firefox).

---

## 🌐 Triển Khai Lên GitHub Pages
Trang web được xây dựng hoàn toàn bằng HTML, CSS và JavaScript thuần, tương thích 100% với **GitHub Pages**. Bạn chỉ cần:
1. Vào repository trên GitHub.
2. Vào **Settings** > **Pages**.
3. Tại mục **Branch**, chọn `main` và thư mục `/(root)`, sau đó nhấn **Save**.
4. Trang web sẽ trực tiếp online trên internet miễn phí!
